# Barochovina

A private shared website for a couple, with memories, movies, series, and travel places.

The movie list and travel bucket list are stored in Supabase, so both people see the same data and changes appear in real time.

## Features

- Memories photo gallery with lightbox view
- Relationship timer
- Shared movie and series list
- Shared travel bucket list
- Add, delete, and update items
- Mark movies as watched
- Mark places as visited
- Realtime updates between browsers
- No login required
