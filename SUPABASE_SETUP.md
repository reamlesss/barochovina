# Shared movie and travel lists

This app uses Supabase's free tier. It has no login: anyone who has the page URL can add, change, or delete items, which matches this private two-person project.

## 1. Create the free database

1. Create a project at [supabase.com](https://supabase.com/).
2. Open **SQL Editor**, create a new query, and run this SQL:

```sql
create table public.movies (
  id bigint generated by default as identity primary key,
  title text not null,
  type text not null check (type in ('movie', 'series')),
  year integer,
  note text default '',
  watched boolean not null default false,
  created_at timestamptz not null default now()
);

create table public.places (
  id bigint generated by default as identity primary key,
  name text not null,
  country text default '',
  note text default '',
  status text not null default 'planned' check (status in ('planned', 'visited')),
  created_at timestamptz not null default now()
);

alter table public.movies enable row level security;
alter table public.places enable row level security;

create policy "shared movies" on public.movies for all to anon using (true) with check (true);
create policy "shared places" on public.places for all to anon using (true) with check (true);

alter publication supabase_realtime add table public.movies;
alter publication supabase_realtime add table public.places;

insert into public.movies (title, type, year, watched) values
  ('Pomocnice 2', 'movie', 2027, false),
  ('Šestý smysl', 'movie', 1999, false),
  ('Game of Thrones', 'series', 2011, true);

insert into public.places (name, country, status) values
  ('Řím', 'Itálie', 'visited'),
  ('Vánoční New York', 'USA', 'planned'),
  ('Laponsko', 'Finsko', 'planned');
```

## 2. Connect this page

In Supabase, open **Project Settings > API**. Copy the **Project URL** and the public **anon key** into `script.js`:

```js
const SUPABASE_URL = "https://your-project.supabase.co";
const SUPABASE_ANON_KEY = "your-anon-key";
```

Do not use the `service_role` key in this page. The anon key is intended for browser use. Because this app intentionally has no login, keep the page URL private; anyone who gets it can edit the lists.

## 3. Publish the page

Use a static host such as GitHub Pages, Netlify, or Cloudflare Pages. Opening `index.html` directly may work, but hosting it makes sharing and realtime updates more reliable.
